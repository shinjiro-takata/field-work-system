# 材料配合管理システム

配合レシピと計量ログの管理、設備点検、レジン使用量の確認を行うWebアプリケーションです。

## 📋 概要

このシステムは以下を実現します：

- **材料管理** - 材料マスターの作成・編集・削除
- **レシピ管理** - 配合レシピの登録と材料の関連付け
- **計量ログ** - 実際の配合時の計量データを記録
- **データ分析** - ログの検索・フィルタリング、Excel エクスポート
- **設備点検** - 日常・週次・月次・定期点検の入力と履歴確認
- **レジン使用量確認表** - 計量ログからの日次使用量集計、補充・在庫照合、上司確認
- **ユーザー管理** - 管理者とワーカーの権限分離

## 📦 セットアップ

### 前提条件

- Docker & Docker Compose
- Git

### インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd material_mixing

# Docker環境を構築・起動
docker-compose up -d --build

# Laravelをセットアップ
docker-compose exec php composer install
docker-compose exec php cp .env.example .env
docker-compose exec php php artisan key:generate

# データベースをマイグレート
docker-compose exec php php artisan migrate

# (オプション) シーダーでサンプルデータを登録
docker-compose exec php php artisan db:seed
```

### アクセス

- **アプリケーション**: http://localhost:8000
- **PhpMyAdmin**: http://localhost:8080

## 📖 使い方

### 1️⃣ 材料管理

#### 材料を追加

1. ダッシュボード → 「🏷️ 材料管理」
2. 「➕ 新しい材料を追加」をクリック
3. 材料名（例：塩、砂糖）と単位（例：g, ml）を入力

#### 材料を編集・削除

- 材料一覧から「✏️ 編集」または「🗑️ 削除」

### 2️⃣ レシピ管理

#### レシピを作成

1. ダッシュボード → 「🆕 新規レシピ作成」
2. レシピ名を入力
3. 「既存の材料」から必要な材料にチェック
4. 各材料の数量を入力して作成

#### レシピを編集

1. 「⚙️ レシピ管理」から編集したいレシピを選択
2. 「✏️ 編集」をクリック
3. 材料の追加・変更・削除が可能
   - **既存材料の変更**: チェック状態と数量を変更
   - **新しい材料を追加**: 「新しい材料を追加」セクションに材料名・単位・数量を入力
   - **材料を削除**: チェックを外す

#### レシピを削除

1. 「⚙️ レシピ管理」から対象レシピの「🗑️ 削除」

### 3️⃣ 計量ログ

#### ログを入力

1. ダッシュボード → 「➕ 計量データの入力」
2. レシピを選択
3. 各材料の実際の計量値を入力
4. 計量日時を設定
5. 備考欄に必要な情報を記入して保存

#### ログを検索

1. 「📋 計量ログの確認」をクリック
2. 以下の条件で検索可能：
   - **期間**: 開始日 ～ 終了日
   - **レシピ**: 特定のレシピを選択

#### データをエクスポート

1. ログ一覧ページで検索条件を設定
2. 「📥 Excelダウンロード」をクリック
3. フィルタリング済みのデータがExcelファイルで出力

### 4️⃣ レジン使用量確認表

1. 管理者がホーム画面の「レジン使用量確認表」から「レジン材料の設定」を開き、材料マスターから使用する2種類を選択します。設定変更後は新規記録に適用され、過去記録の材料は変わりません。
2. 「新規入力」で日付を選ぶと、配合手順確認書の計量ログから同日の対象材料の実使用量を集計します。レシピの配合値は参照しません。
3. 材料設定画面に各レジンの初回在庫を登録します。初回入力は設定値を参照し、以降は材料ごとの最終在庫確認量を前回在庫として使います。計算在庫は「前回在庫 + 補充数 - 使用量」です。
4. 作業者が実在庫を入力し、計算在庫と異なる場合は差異の理由を記録します。実在庫を次回計算の基準にします。
5. 上司は確認欄に氏名を入力して確認済みにできます。履歴から記録を修正すると、後続記録の計算在庫も再計算されます。

### 5️⃣ ユーザー管理（管理者のみ）

#### ユーザー一覧

- ダッシュボード → 「👥 アカウント管理」

#### ユーザーを編集

1. 対象ユーザーの「✏️ 編集」をクリック
2. 名前、メール、パスワード、権限を変更
3. パスワード欄を空白にすると変更なし

#### ユーザーを削除

1. 対象ユーザーの「🗑️ 削除」をクリック
2. ※自分自身は削除不可

## 🗄️ データベース構造

### テーブル一覧

- **users** - ユーザー情報
- **materials** - 材料マスター
- **recipes** - レシピ
- **recipe_materials** - レシピと材料の関連付け（数量を保持）
- **production_logs** - 計量ログ
- **production_log_materials** - 計量ログと材料の関連付け（実績値を保持）
- **resin_usage_settings** - 使用量を集計する材料の設定
- **resin_usage_records** - レジン使用量の日次記録
- **resin_usage_items** - 材料ごとの使用量、補充、在庫照合・調整

## 🔧 トラブルシューティング

### Docker コンテナが起動しない

```bash
# コンテナを再起動
docker-compose restart

# ログを確認
docker-compose logs php
```

### データベース接続エラー

```bash
# マイグレーションを再実行
docker-compose exec php php artisan migrate:fresh
```

### ファイルパーミッションエラー

```bash
# Laravelストレージディレクトリの権限を修正
docker-compose exec php chmod -R 777 storage bootstrap/cache
```

## 📝 主な機能詳細

### 計量ログのフィルタリング

- 複数条件（期間、レシピ）での同時フィルタリングに対応
